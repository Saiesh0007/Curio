# Design System

## Brand Identity
- **Name:** CURIO
- **Tagline:** LEARN. PLAY. DO. CREATE.
- **Personality:** Curious, Playful, Intelligent, Safe, Warm, Exploratory, Premium, Trustworthy.

## Aesthetics
- **Vibe:** Premium modern startup + Interactive game world.
- **Avoid:** Generic SaaS templates, clutter, excessive glassmorphism, childish clip art, rainbow vomit.

## Key UI Elements
### Navigation
- Prominent "PITCH DEMO" button.
- Links: Explore World, How It Works, For Parents, For Schools, Safety.

### The Learning World
- Not a dashboard. Feels like an explorable map.
- 7 Locations as interactive cards/islands/buildings:
  1. Marketplace
  2. Science Lab
  3. Space Station
  4. Creative Studio
  5. Inventor's Workshop
  6. Explorer Forest
  7. Story Village

### Shared Components (To be styled consistently)
- `MissionHeader`
- `XPDisplay`
- `SkillProgress`
- `WorldCard`
- `BadgeCard`
- `ProgressBar`
- `ParentInsightCard`
