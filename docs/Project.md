# Project Overview

## Product Concept
**CURIO** is a personalized learning world for children aged 5–8.
It is NOT simply a video platform, quiz app, or math game. It is an interactive world that connects digital learning to real-world application.

## Core Loop
1. **LEARN:** Understand a concept.
2. **PLAY:** Practice through an interactive challenge.
3. **DO:** Apply learning in the real world.
4. **CREATE:** Build something using what was learned.

## Purpose
This frontend prototype will serve as the LIVE PRODUCT DEMO for a college startup/business competition called "Pitch Perfect". It must feel like a real, polished edtech startup prototype ready for investors.
